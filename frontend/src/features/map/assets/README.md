# Decorative Milky Way reference

`milky-way.jpg` is NASA SVS's 1024 × 574 preview of the 2MASS galactic-plane image:

- [Source and credits](https://svs.gsfc.nasa.gov/30020/)
- [Original preview JPEG](https://svs.gsfc.nasa.gov/vis/a030000/a030000/a030020/2mass-galactic-plane_print.jpg)
- Credit: NASA's Goddard Space Flight Center. The underlying 2MASS project is a joint effort of the University of Massachusetts Amherst and Caltech's Infrared Processing and Analysis Center.
- [NASA reproduction guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/)

The original JPEG is unmodified. CSS crops, fades, and partially desaturates it into a small decorative background behind the map. It is not geographic or event evidence. The opaque full-viewport sky and Mapbox's blue atmospheric glow retain their existing settings.
